# 脱毛・リラク SOCU サイト

福岡・博多駅から徒歩5分の男性専門リラクゼーションサロン「脱毛・リラク SOCU」のWebサイトです。

日本語と英語を1ページに入れて、右上のボタンで切り替える方式にしています。

**確認用サイト**: https://oasislife-web.github.io/socu-relaxation/

> ⚠ これは**キシさんに見てもらうための確認用**の公開です。
> `index.html` に検索避け(`<meta name="robots" content="noindex, nofollow">`)を入れてあるので、
> Googleなどの検索結果には出ません。**本番ドメインで公開するときは、その1行を必ず削除してください。**

---

## サイトを見る方法

`index.html` をダブルクリックするとブラウザで開きます。

> ※ 地図(Googleマップ)と英語フォントの表示にはインターネット接続が必要です。

## ファイル構成

| ファイル / フォルダ | 中身 |
| --- | --- |
| `index.html` | ページの文章と構成すべて |
| `styles.css` | 色やレイアウトなどの見た目 |
| `assets/` | 公開用の画像・動画(軽量化済み) |
| `assets/img/` | 写真とロゴ |
| `_src/` | **元データ置き場。** スマホ写真の原本と4K動画。サイトには使いません |
| `docs/` | ヒアリングシート・店舗情報・構成案。**打ち合わせ用の資料** |

`_src/` と `docs/` はサイトに載せるものではないので、公開(アップロード)しません。

## よくある更新のやり方

### 文章を直す

`index.html` をメモ帳などで開いて、直したい文章を探して書き換えます。

`< >` で囲まれた部分は「枠組み」なので触らず、**その間の日本語だけ**を変えるのが安全です。

```html
<span lang="ja">ここが日本語</span>
<span lang="en">This is English</span>
```

日本語と英語がセットで並んでいます。**片方だけ直すと、もう片方は古いままになる**ので、両方直してください。

### 料金を変える

`index.html` の中で金額(例: `¥13,000`)を検索して書き換えます。
価格は日本語・英語で共通なので1か所だけでOKです。

### 今月のキャンペーンを変える

`index.html` の中の `note--offer` という部分を探してください。

```html
<p class="note note--offer">
  <span lang="ja"><strong>1週間前までのご予約で、上記3コースが各 ¥1,000 オフ。</strong></span>
  <span lang="en"><strong>Book at least one week ahead and take ¥1,000 off any of the three.</strong></span>
</p>
```

この中の文章を書き換えるだけです。

### 色を変える

`styles.css` の一番上にある `:root { }` の中に色がまとめてあります。
ここを変えると全体の色が一括で変わります。

| 変数名 | 使いどころ |
| --- | --- |
| `--paper` | ページの背景(白しっくい) |
| `--pine` | ロゴの濃い緑。見出しやボタンに使う主役の色 |
| `--leaf` | ロゴの黄緑。ごく少量のアクセント |
| `--lamp` | 店内のランプの色。注意書きなどに |
| `--ink` | 文字の色 |

### 写真を差し替える

1. 新しい写真を `assets/img/` に入れる
2. `index.html` の中で古いファイル名(例: `assets/img/room-bed.webp`)を検索して書き換える

**そのまま入れるとファイルが重すぎます。** スマホ写真は1枚3〜5MBあるので、
横1080pxくらいのWebPに変換してから入れてください(変換にはffmpegを使っています)。

## 画像・動画の軽量化コマンド

このPCには [ffmpeg](https://ffmpeg.org/) が入っています(`winget install Gyan.FFmpeg` で導入)。

写真1枚をWebPに変換:

```
ffmpeg -i 元の写真.jpg -vf "scale=1080:-2" -quality 74 assets/img/名前.webp
```

動画をヒーロー用に軽量化(音を消して2MB以下に):

```
ffmpeg -i 元の動画.mp4 -t 9 -an -vf "scale=1280:-2,fps=25" -c:v libx264 -crf 30 -preset slow -movflags +faststart -pix_fmt yuv420p assets/hero.mp4
ffmpeg -i 元の動画.mp4 -ss 2 -frames:v 1 -vf "scale=1280:-2" -quality 70 assets/hero-poster.webp
```

`hero-poster.webp` は、動画が読み込まれるまでの間に表示する静止画です。動画を差し替えたら**これも一緒に作り直してください。**

## 技術メモ

- ビルド不要。素のHTML/CSSと、言語切り替え用の小さなJavaScriptだけです
- 言語切り替えは `<html>` に `lang-en` クラスを付け外しして、CSSで表示を切り替えています。選んだ言語はブラウザに記憶されます
- ヒーロー動画は自動再生・無音・ループ。「視差効果を減らす」設定の人には静止画だけを表示します
- 電話番号は意図的に載せていません(電話予約を受け付けていないため)
